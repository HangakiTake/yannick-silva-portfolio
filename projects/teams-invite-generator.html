Teams invite generator (dry run)

This tool turns a school's course sheet, one row per course, into recurring Microsoft Teams meeting series in each teacher's calendar. It removes holidays (festivos), invites the attendees and logs every row. What it handles:

  • Messy Spanish input: "lunes y miércoles", "L-X", "lunes a jueves", 18.30 or 20h times, and festivo ranges such as "21-12-2026 a 06-01-2027".
  • Row-by-row errors: a bad row is logged with a reason and never stops the others.
  • Clock changes: times are sent in Europe/Madrid so the October clock change does not move a class.
  • No duplicates: each series has a stable key, so a rerun updates rather than duplicates.

This demo is offline. It writes a dry-run workbook (Log, Series, Occurrences) and the exact Microsoft Graph requests a live run would send. Nothing is sent. Live invites need the client's Microsoft 365 tenant. The Power Automate flow for that, with an approval step, a log list and the permissions needed, is written up as a design.

How it was tested

  • 55 tests pass, 0 fail.
    • 33 parsing cases (weekdays, dates, times, festivos, attendees).
    • The class dates for 5 sample courses equal calendars written by hand before the run: 92 classes, with 10 festivos removed.
    • 7 seeded bad rows plus duplicate, ambiguous-date and holiday-year-typo cases are each logged with the right reason.
    • Graph payload shape and the idempotency key are checked.
  • The client's own 3-row sample sheet (run locally, not published): 3 of 3 rows ready, 66 classes, 1 festivo removed.
  • Skeptical-buyer review: 13 messy inputs were tried.
    • It found that a duplicated row would have created double invites. That is now an Error.
    • Score: 4 of 8 gate items pass. The fails are real data, integration, security and cost, because no tenant exists yet.

Honest caveats:

  • Nothing has been run against Microsoft Graph or Power Automate, so the payloads follow the Graph v1.0 docs but no tenant has accepted them.
  • Google Meet rows are marked "phase 2" and not built.
  • Dates are read day first, so 03/04/2027 becomes 3 April. It is flagged for a check, not refused.
  • Synthetic teacher names and example.com addresses only.
