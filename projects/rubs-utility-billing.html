RUBS utility billing workbook

This Excel workbook splits each property's water, sewer, trash, gas and other bills across its units, using ratio utility billing (RUBS). It covers:

  • Split methods: by occupant-days, square feet or equally, with mid-period move-ins and move-outs pro-rated by day.
  • Owner costs: an owner-paid share, vacant-unit shares and unit discounts are charged to the owner.
  • Exclusions: a service can be switched off per unit.
  • Rounding: done in cents, so every bill ties out exactly.
  • Monthly use: every rule sits in an input table, so a new month needs no formula edits.
  • Checks: a Manual_Check sheet rebuilds any one unit's charge from scratch, and an Exceptions sheet counts every input problem.

Capacity: 10 properties, 40 units, 30 bills a month. All data is synthetic.

How it was tested

The workbook is recalculated in LibreOffice and compared cent by cent with a separate Python version of the same maths, which uses exact fractions and reads no workbook formulas.

  • 56 tests pass, 0 fail.
    • Every bill reconciles to the cent on 6 clean data sets, including a random full-capacity file (40 units × 30 bills).
    • Workbook and Python agree on every charge.
    • Manual_Check matches on 6 chosen bill/unit pairs.
    • Changing inputs only (occupants, owner %, a new month) recalculates correctly.
    • 21 of 21 seeded input errors are flagged.
    • 0 formula errors in 7 workbooks.
  • Sample month: 13 of 13 bills reconcile. $6,794.73 billed = $6,427.52 charged to tenants + $367.21 owner. 106 of 106 unit charges match the Python version.
  • Speed: about 1 s to recalculate a full-capacity file in LibreOffice.
  • Skeptical-buyer review: 11 messy inputs were tried.
    • It found that an amount or date typed as text was silently read as $0. That is now flagged, with regression tests.
    • Score: 6 of 8 gate items pass. The fails are "no real bills or rent roll" and "no import from a property system".

Honest caveats:

  • Tested in LibreOffice, not desktop Excel. It needs Excel 2019 or 365 for MAXIFS.
  • Synthetic data only.
  • Credits (negative bills) are flagged, not split.
  • A unit ID with a stray space is flagged, but until it is fixed that unit's share goes to its neighbours.
  • RUBS rules differ by US state and city, so this is a calculation tool, not legal advice.
