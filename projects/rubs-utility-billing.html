RUBS utility billing

An Excel workbook that splits water, sewer, trash, gas and other utility bills across units in more than one property. Partial months, vacancies, excluded services, discounts and an owner-paid share stay in the formulas. A separate Python reference checks the cents. All properties and figures are synthetic.

How it was tested

pytest runs the Python reference and, separately, recalculates the workbook in LibreOffice and compares every in-scope line.

  • 38 tests pass, including reconciliation to the cent for every included bill, LibreOffice matching the Python reference, the manual check for every included bill, input edits with no formula changes, and the three seeded exceptions (negative bill, occupancy on a vacant unit, a service-period gap).
  • 0 tests fail in that suite.
  • Not run in desktop Excel. Recalculation was LibreOffice only.

RUBS rules vary by US state and local law. This is a calculation tool, not legal advice. Credits (negative amounts) are flagged and not allocated. Overlapping occupancy is flagged, not repaired, and can overstate occupied days until the dates are fixed. Common-area subtraction, taxes, late fees and meter reads are not built.
