Workday automation audit

One fictional solo bookkeeper describes a normal week in plain text (typos, ranges, a voice-note style second week). The kit lists the recurring tasks, ranks them by hours saved against effort and risk, and picks n8n, Make, a Claude step, a spreadsheet, or "don't automate", with a reason. Personal details are stripped before any model would see the text. The top task, drafting replies to new inquiries, comes back as an n8n workflow plus a one-page guide. Drafts wait for a person. Nothing is sent.

This is one person's week, and the point of it is to keep that week private. It is not a company-wide process inventory.

How it was tested

25 tests pass, 0 fail (mock mode, no API key). Three invented week notes: 53 mentions, 23 of them messy, 30 distinct tasks.

  • 48/48 labelled tasks found, and 48/48 have a repeat rate and a duration inside the hand-labelled range. 5/5 unclear lines are on the questions list. None of the labelled lines were dropped.
  • 65/65 planted names, emails, phones, amounts, and addresses removed. The placeholder map puts the text back exactly. The mock model saw 0 email addresses and 0 phone numbers.
  • Tool pick matched the hand labels on 30/30 tasks.
  • 32/32 fake inquiries saved as drafts waiting for approval, 0 sent. Category, urgency, and service matched on 32/32. Eight extra paraphrases in the stress tests also matched.
  • The n8n file parses: 11 nodes, every connection names a real node, credentials are names only, and the send node is disabled behind a human-approval step.

Honest caveats:

  • The bookkeeper, the week notes, and the inbox are fictional. The answer key was written for those notes.
  • The accuracy figures are from mock mode. Claude was not called. Live mode reports "not run" when no API key is set.
  • The n8n workflow was checked structurally. It was not imported into a running n8n, and nothing was saved to a real Gmail or Google Sheet.
  • Redaction is a set of rules. A bare first name with no greeting and no surname can remain. On n8n Cloud the Gmail trigger has already seen the raw email unless saved executions are turned off.
  • Cost on the guide is a dated assumption (2026-11-03): €24 a month for n8n Cloud Starter billed monthly, and about $0.02 of Claude Haiku 5.5 for 80 short inquiries. Recheck both before buying. The two currencies are not added together.
