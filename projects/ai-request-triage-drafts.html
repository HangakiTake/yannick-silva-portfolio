Incoming request drafts

A small fictional home-services company gets quote, booking, billing and complaint messages all day. This reads a sample inbox (email files, a JSON export and a web form), pulls out who is asking and what they need, and saves a reply for a person to check. What it handles:

  • Messy mail: forwarded threads, signatures, quoted replies, HTML-only bodies, French, Portuguese and Spanish, empty messages and spam.
  • A person in the loop: complaints, legal threats, payment disputes, low confidence and ambiguous dates are flagged. The draft is a file. Nothing is sent.
  • No invented prices: a quote uses only the prices in the tone file, and only for the service the customer named. A booking or a complaint draft has no dollar amount.
  • Same inbox twice: the second run adds no rows and no drafts.

This demo is offline. Mock mode needs no API key. The notes for Zapier and Power Automate say which accounts and which prices were current on 3 Nov 2026. Those tools were not connected.

How it was tested

  • 24 tests pass, 0 fail (Python 3.12.3, pytest 9.2.0). One Starlette warning about its HTTP client. It does not fail a test.
  • 47 synthetic messages, 29 of them messy. Labels were written before the extractor.
    • Request type: 47 / 47. Misses: none.
    • Name, email, phone, dates and amounts: 235 / 235. A field that was empty in the label stayed empty.
    • 16 / 16 requests that need a person were flagged, including 5 low-confidence ones.
    • 12 / 12 malformed model replies were rejected. 0 were kept.
    • 0 of 47 drafts contained a price, date or promise outside the request or the tone file.
  • Second run: 0 new rows and 0 new drafts.
  • 300 plain emails: 0.431 seconds on this machine, mock mode.
  • Live model: not run. No API key was set.

Honest caveats:

  • The messages are synthetic, and the labels were written by the same person who built the extractor. 47/47 is this set, not a real inbox.
  • The figures above are mock mode. A live OpenAI or Anthropic run was not done.
  • Zapier and Power Automate are described in the handoff, including list prices read on 3 Nov 2026. They were not connected.
  • "Tomorrow" is not turned into a date. The draft asks which day.
