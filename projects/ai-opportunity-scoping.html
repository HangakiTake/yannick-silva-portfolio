AI opportunity scoping

Pebblecart is a made-up home-goods shop. This kit reads a messy list of how the shop works, scores each process for payoff against effort, and recommends what to build: a plain workflow, a function-calling agent, search over the shop's own documents, a classic model, or nothing. It then writes a short decision note with the cost, the risks and a phased plan.

The top row is the support queue. The working prototype is that agent. It looks up an order, checks the refund policy, issues a refund only under the cap, and hands anything else to a person. The same tool schema is used from Python and from a small TypeScript client, against a fake shop API. Both run with no OpenAI key.

How it was tested

  • 17 Python tests pass, 0 fail. 3 Node tests pass, 0 fail. Run on 3 November 2026, Python 3.12.3 and Node 22. No API key.
  • 44 inventory rows: 30 scored, 14 listed as exceptions, 0 dropped. 20 of the rows were typed messy on purpose (ranges, ~180/week, 1,5 h, 6k, a pasted formula).
  • 77 of 77 hand-labelled times, volumes and error rates normalised correctly.
  • Architecture agrees on 29 of 30 hand labels. The miss is the blog-tag row: a person would call it a classic model, the rubric says don't automate. It is explained, not relabelled.
  • 36 of 36 scripted support conversations called the right tool with valid arguments. 13 of 13 out-of-policy refunds were escalated and none were paid. 28 of 28 bad tool arguments were rejected. A direct refund of $120, skipping the planner, was also refused.
  • The support queue's estimated OpenAI cost is $12.75 a month, from the token assumptions and the price list checked on 3 November 2026.

Honest caveats:

  • Pebblecart is not a real company. The process list and the orders are synthetic.
  • The 36 conversations were answered by the deterministic mock, not by a live model. That checks the tools, the argument validation and the refund gate. It does not show how a model handles a sentence that was not scripted. Live mode was not run.
  • The 29-of-30 architecture score is against labels written from the rubric in this repo, not against a second person.
  • The demo clock is frozen on 3 November 2026 so the sample orders stay inside the refund window.
