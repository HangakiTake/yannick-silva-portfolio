## Demos

### [RUBS utility billing](demos/rubs-utility-billing/)

Excel workbook that allocates water, sewer, trash, gas, and other utility bills across units in more than one property. Occupant-days, partial months, vacancies, excluded services, discounts, and an owner-paid share. Formulas stay in the file. A Python reference checks that every included bill ties to the cent.

Synthetic data. RUBS rules vary by US state and local law. The workbook is a calculation tool, not legal advice.
